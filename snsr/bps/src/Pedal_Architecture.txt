Recommended diagnostics:
1. Frame timeout
2. CRC error
3. Sync/period error
4. Raw range error
5. Dual-channel plausibility error
6. Stuck-at value / rate-of-change error
7. Sensor status nibble error
8. Supply diagnostic if available
9. Internal software watchdog / alive counter
10. Latched safe reaction after qualified debounce
