# M 法、T 法、M/T 法

## 1 M 法、T 法、M/T异同

三种方法本质上都是在测：

$$
f=\frac{\text{单位时间内的脉冲数}}{\text{时间}}
$$
区别在于：**到底是固定“时间”测脉冲，还是固定“脉冲”测时间。**


## 2 M法：固定时间数脉冲

M 法又叫**定时计数法**。

例如我们规定：$测量窗口 = 10 ms$

在这个10 ms里面数到了：$N = 20个脉冲$

那么：$f=\frac{N}{T_g}$

例如：$f=\frac{20}{0.01}=2000Hz$

如果一个车轮每转：$Npp = 48 pulse/rev$

那么：$RPM=\frac{60f}{48}$



**M法的硬件结构**

```
                    Wheel Sensor
                         │
                         ▼
                  Edge Detection
                         │
                         ▼
                     Counter
                         │
              ┌──────────┴──────────┐
              │                     │
          Timer Gate            Pulse Count
              │                     │
              └──────────┬──────────┘
                         │
                    10ms结束
                         │
                         ▼
                   Pulse Number M
                         │
                         ▼
                  Frequency = M/Tg
```


## 3 M法为什么高速好用？

假设：

$$
测量窗口 = 10ms\\
高速：100个脉冲
$$
那么1个脉冲的量化误差只有：$\frac{1}{100}=1\%$

如果：$1000个脉冲$

误差约：$0.1\%$

所以：**脉冲越多，M法越精确。**


## 4 但是M法低速会非常差

例如：

$$
10ms测量窗口\\
低速只来了：1 pulse
$$
那么：

$$
0 pulse → 0 km/h\\
1 pulse → 某个很大的速度\\
2 pulse → 两倍速度
$$
例如：

```
0
1
0
1
0
1
```

结果就是：

```
0
V
0
V
0
V
```

这就是：**轮速低速情况下误差很大。**

原因不是传感器一定有问题，而是：**M法的时间量化导致低速时脉冲数量太少。**


## 5 T法：固定一个脉冲测时间

T法恰好反过来。

不再：固定10ms数多少脉冲

而是：固定一个脉冲测两个相邻边沿之间的时间

例如：

```
       ↑                   ↓
───────┘                   └──────
       T1                  T2

        ←────────T────────→
```

$$
T=T_2-T_1\\
频率：f=\frac{1}{T}
$$


## 6 T法为什么低速好？

假设：
$$
低速：T = 100ms\\
Timer：1us/tick
$$
那么：

$$
T = 100000 ticks
$$
测量分辨率非常高。



而M法10ms窗口，可能一个脉冲都没有。



因此：**低速应该优先使用T法。**


## 7 但是T法高速又会出现问题

例如：
$$
T = 10us\\
Timer：1us/tick
$$
只有：$10 ticks$

那么一个Timer tick的误差就是：$\frac{1}{10}=10\%$

所以：**高速时T法的时间量化误差越来越明显。**

这就形成了一个非常漂亮的互补关系：

| 速度   | M法      | T法            |
| ------ | -------- | -------------- |
| 高速   | 好       | 差             |
| 中速   | 好       | 好             |
| 低速   | 差       | 好             |
| 极低速 | 很差     | 较好，但更新慢 |
| 0 km/h | 无法区分 | 必须Timeout    |


## 8 M/T法：两者结合

M/T法就是：**在一个测量周期内，同时统计脉冲数 M 和计时器计数 T。**

可以理解成：

```
                 测量窗口
        ├─────────────────────┤

        ↑    ↑    ↑    ↑
        │    │    │    │
        └────┴────┴────┴──────
             M个脉冲

        Timer：
        T0 ───────────────── T1

        Timer Count = ΔT
```

于是：$f=\frac{M}{\Delta T}$

如果Timer频率：$f_{timer}$

那么：$f_{pulse} = \frac{M f_{timer}}{\Delta Counter}$


## 9 M/T法为什么比单纯M法更好？

M法：$f=\frac{M}{T_g}$

其中：$Tg = 软件固定的测量窗口$



M/T法：$f=\frac{M}{T_{actual}}$

其中：$Tactual = 实际两个测量边界之间的Timer时间$



因此避免了：测量窗口与实际脉冲边沿不同步造成的误差。

例如：

```
固定10ms窗口：

窗口：
|--------------------|

脉冲：
    ↑    ↑    ↑    ↑
```

窗口刚好截断脉冲。

M法只知道：

```
M = 4
Tg = 10ms
```

而M/T法可以让测量边界与脉冲同步：

```
        ↑              ↑
        │              │
        └──────────────┘
              ΔT
```

所以：$f=\frac{M}{ΔT}$

## 10 三种方法的工程选择

| V              | algorithm |
| -------------- | --------- |
| 0 ~ V_LOW      | T法       |
| V_LOW ~ V_HIGH | M/T法     |
| > V_HIGH       | M法/M/T法 |
